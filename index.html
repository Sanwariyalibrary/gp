📖 Excel में Row & Column अलग-अलग कैसे आएंगे?

  1. PDF upload करें या Sample data button दबाएं
  2. 📥 Excel Download (Proper Columns) button दबाएं
  3. Excel file open करें — हर field की अलग column होगी:
    A = क्र.सं. B = EPIC ID C = नाम D = पिता/पति E = मकान F = आयु G = लिंग H = वार्ड I = गाँव J = मोबाइल
  4. हर voter की अलग row होगी
  5. Ward-wise sheets चाहिए तो 📊 Ward-wise Excel button दबाएं — हर Ward की अलग sheet बनेगी
